
# ✳ NEBULA — Interactive Digital Universe

NEBULA is a cinematic, space-inspired interactive website. Explore a collection of fictional planets in a futuristic environment.

## Features

- Real-time 3D planet rendering with Three.js
- Procedurally generated surface textures
- Planet atmosphere and cloud layers
- 360-degree drag rotation
- Automatic planet rotation
- Animated starfield
- Interactive planet cards
- Planet information modal
- Mouse-follow ambient glow
- Interactive animated portal
- Scroll reveal animations
- Mobile responsive design
- Touch support

## Technologies Used

- HTML5
- CSS3
- JavaScript ES Modules
- JSON
- Markdown
- Three.js

## Installation

No installation is required.

The 3D engine is loaded from jsDelivr CDN.

## Deploy on GitHub Pages

1. Upload all five files to your repository root.
2. Open repository Settings.
3. Select Pages.
4. Select Deploy from a branch.
5. Choose main.
6. Select / (root).
7. Click Save.
8. Wait for deployment to finish.

## Interaction

- Drag the main planet horizontally or vertically to rotate it.
- The planet rotates automatically when not being dragged.
- Scroll to discover more sections.
- Click a planet card to open its information.
- Use the navigation to jump between sections.

## Notes

Internet access is required to load the Three.js module from CDN.

The planets use procedural textures generated by JavaScript and are fictional visual worlds, not scientifically accurate planetary maps.
