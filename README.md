
# ✳ NEBULA — Interactive Digital Universe

A cinematic, interactive space-themed website designed to feel like a journey into another dimension.

## Features

- Animated particle stars using Canvas
- Floating planets
- Rotating orbital rings
- Mouse-follow ambient glow
- Mouse parallax movement
- Scroll reveal animations
- Interactive universe cards
- Modal interactions
- Responsive mobile layout
- Reduced motion accessibility support

## Technologies

1. HTML5 — Structure
2. CSS3 — Design and animations
3. JavaScript — Interactivity and Canvas
4. JSON — Universe data
5. Markdown — Documentation

## Run locally

Open `index.html` using a local development server.

JSON data is loaded with Fetch, so avoid opening directly with `file://`.

## GitHub Pages

1. Push files to GitHub.
2. Open repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Save.
